## Coding Guideline

PRJ2-Extractor is a vibe-coded program, but if you'd like to improve something, feel free to do a PR!
AI generated code is ok

## Issues

Have you found a problem with the program?

Make an issue! Describe clearly your problem, send screenshots if you can

## Feature Requests

Do you have an idea for this program?

We'd happy to hear it! On the issues, you can also create a Feature Request. Describe clearly what you'd like to see on the program

## Pull Requests

Would you like to implement a features you did on the repo?

Feel free to do it! Describe clearly what your PR does, check if you you used AI code, and send screenshots if you can.
Follow the examples below for a good PR content:

### PR Content

Bad PR Content:
```
Implemented TR1 support
```

Good PR Content:
```
This PR adds the support for TR1 Levels

(Eventaully Screenshots)

```

### PR Commit Message

Bad:

`Added support for TR1 levels`

Good:

`extractor: implemented tr1 levels support` or `textures: fixed mismatched QA on walls on TR2 levels`
