# PRJ2 Extractor

PRJ2 Extractor is a tool for extracting from Tomb Raider levels, prj2 files that contains the geometry of the level.

## Disclaimer

The TRLE PRJ extraction, the TR4 level parser and the UI is based on sapper-trle's TR42PRJ source code, this program is his code translated to C#, the original code is this ()[https://github.com/sapper-trle/TR42PRJ].
